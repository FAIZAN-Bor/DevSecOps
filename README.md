# 🔐 DevSecOps Demo Project

**Topic:** DevSecOps — Integrating Automated Security Scanning into CI/CD Pipelines
**Course:** DevOps | 2024-2025

## Tools Used
- Bandit — Python code security scanner (SAST)
- Safety — Dependency CVE scanner
- GitLeaks — Secret detection in Git history
- Trivy — Docker container vulnerability scanner
- GitHub Actions — CI/CD pipeline automation
- Docker — Application containerisation
- pytest — Unit testing

## How to Run
```bash
pip install flask pytest bandit safety
python app/app.py
```
Visit http://localhost:5000
